# ADR 0002: Runtime 동작 계약과 독립 Builder 배포

- 날짜: 2026-11-07
- 상태: **Accepted — 설계 검토 후 사용자 위임에 따라 구체화한 v1 기준**
- 관련 문서: [요구사항](../product-requirements.md), [아키텍처](../architecture.md), [프로젝트 형식](../project-format.md), [빌드·배포](../build-and-distribution.md)

## 배경

ADR 0001의 제품 방향은 유지한다. 구현자가 동작 종료·편집 전환·빌드 입력을 다르게 해석하지 않도록 미정 사항을 결정한다. 아래 결정은 구현·성능 검증 완료를 뜻하지 않는다.

## 결정

1. **초기 제작자는 CLI·JSON과 로컬 도구체인을 사용할 수 있는 사람**이다. Builder + Player가 P0, 폼 기반 Studio가 P1이다. 생성 앱을 받는 사용자에게는 개발 도구가 필요 없다.
2. 화면은 **TypeScript + Vite + Canvas 2D**로 구현한다. Player와 최초 Studio 폼은 별도 UI 프레임워크 없이 시작한다. 공유 Rust 코어에서 JSON Schema와 TypeScript DTO를 생성·검사하고, 프레임워크 추가는 후속 ADR로 결정한다.
3. Runtime 코어는 Tauri·OS API·파일 I/O·실시간 시계에 직접 의존하지 않는다. Host가 정규화 이벤트·단조 시각·모니터 상태를 주입한다. 동작 선택·종료·중단과 위치 계산은 Rust가 소유한다.
4. 애니메이션은 **기본 상태와 일회성 반응**으로 구분한다. 기본 상태는 속도 구간·이동·idle 순서다. `move.animation`으로 걷기를 연결하고 범용 effect 배열·사용자 스크립트는 도입하지 않는다. 일회성 반응은 반복을 금지하고 중단된 반응은 폐기한다. 종료 후 현재 기본 상태를 처음부터 재생한다. 속도·키워드는 [ADR 0003](0003-global-typing-reactions.md)을 따른다.
5. 사용자 입력 설정과 실제 감지 상태를 분리한다. 편집·Player 설정 창·숨김·감지 중단에서는 입력 동작과 held 상태를 해제한다. 재개 시 기존 입력을 재생하지 않으며 새 입력 전이부터 반응한다.
6. 사용자가 지정한 **기본 배치 위치만 저장**한다. 자동 이동 위치는 메모리에 두고 재시작 시 기본 배치로 돌아간다. 편집 완료는 현재 위치를 새 기본 배치로 확정하고, 편집 취소는 진입 직전 위치를 복원한다.
7. Builder는 **OS별 CLI 릴리스와 버전 고정 템플릿 팩**으로 배포한다. 팩에 Player·공통 Rust 소스·웹 소스·잠금 파일·스키마·라이선스를 포함한다. 작업 디렉토리 안에서 소스 의존성이 닫혀야 하며 원래 저장소나 외부 절대 경로에 의존하지 않는다. 첫 빌드의 공식 의존성 다운로드와 로컬 컴파일은 허용한다.
8. 빌드는 **경로·크기 사전 검사 → snapshot → snapshot 최종 검증 → hash 확정 → 생성·컴파일·패키징** 순서다. 최종 검증 뒤에는 원본 프로젝트를 다시 읽지 않는다. 불일치·복사 중 변경은 실패로 반환하고 사용자가 재시도한다.
9. 최초 지원 기준은 **Windows 11 25H2 이상 x64, macOS 15 이상 arm64**다. 입력은 Windows Raw Input, macOS listen-only session event tap을 OS API 바인딩으로 직접 감싼다. 범용 입력 후킹 패키지를 기본 의존성으로 두지 않는다. 미검증 플랫폼을 정식 지원으로 표시하지 않는다.
10. M0에서 두 OS의 입력·오버레이와 함께 **서로 다른 두 앱의 최소 패키징·외부 기기 실행**까지 증명한다. 운영 가능한 Builder 작업 관리와 전체 P0 완료는 M3에서 검증한다.

## 결과와 제한

- 동일 입력·시각에 대한 결정적 코어 테스트가 가능하고 Studio와 Player의 규칙을 공유한다.
- 이동 애니메이션을 지원하되 복잡한 조건 조합·노드 그래프를 v1에 넣지 않는다.
- 제작자는 여전히 Rust·Node·OS 빌드 도구를 준비해야 한다. Builder 설치만으로 도구체인이 자동 설치되지는 않는다.
- 입력 장치별 식별이 없는 macOS tap은 세션 통합 상태를 사용한다. 장치별 키 상태나 모든 특수 키를 보장하지 않는다.
- 성능 예산은 목표이며 기준 기기와 잠금 버전은 M0 시험 기록에서 확정한다. 실제 API 제약이 드러나면 근거와 함께 이 ADR 및 관련 계약을 변경한다.

2026-11-07: Studio 제공 방식, 직접 드래그, 리소스 확장과 속도 타이밍 기본값은 [ADR 0004](0004-project-studio-and-media.md)로 대체한다. 위 결정의 이전 고정 타이밍·일정은 역사적 기록이다.
