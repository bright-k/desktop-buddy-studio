# Desktop Buddy Studio 문서

작성·검토 기준일: 2026-11-07 (Asia/Seoul)

Desktop Buddy Studio는 **설정과 리소스로 여러 종류의 데스크톱 캐릭터 프로그램을 정의하고, 각각 독립 실행 앱으로 빌드하는 제작 도구**다. 생성된 앱은 제작 도구 없이 설치·실행되어야 한다.

## 확정된 방향

- Windows와 macOS를 지원한다.
- Tauri + Rust를 사용한다. 화면 구현용 TypeScript는 상세 설계 제안이다.
- 위치·크기 조절, 전역 키보드·마우스 반응을 공통 런타임이 제공한다.
- 프로젝트마다 이름·아이콘·앱 식별자·리소스·입력 동작을 독립적으로 정의한다.
- 유료 공식 인증서와 공증을 배포의 전제 조건으로 두지 않는다. 필요한 로컬 서명·셀프 서명은 허용한다.
- OS의 미서명 앱 실행 승인과 입력 감지 권한 승인을 구분한다.

## 제품을 이루는 세 부분

1. **Builder**: 프로젝트를 검증하고 공통 런타임과 결합해 독립 앱을 빌드한다. CLI와 라이브러리로 먼저 제공한다.
2. **Runtime / Player**: 생성된 앱에 포함되는 실행 엔진이다. 캐릭터 표시, 입력 반응, 위치·크기, 트레이와 사용자 설정을 담당한다.
3. **Studio**: 프로젝트 편집·미리보기·빌드를 제공하는 GUI다. Builder와 Runtime이 동작한 다음 추가한다.

MVP의 핵심 증명은 **코드 변경 없이 서로 다른 두 프로젝트를 빌드하고, 제작 도구가 없는 다른 컴퓨터에서 각각 실행하는 것**이다. Studio의 풍부한 편집 기능보다 이 경로를 먼저 완성한다.

## 문서의 상태

이 문서는 구현 전 설계다. 기능이 구현되었거나 성능·설치가 검증되었다는 뜻은 아니다. 사용자가 확정한 사항과 설계 제안을 구분했으며, 제안된 OS 하한·성능 예산·프로젝트 스키마는 첫 기술 검증에서 조정할 수 있다. 실제 변경은 관련 요구사항·ADR·프로젝트 버전을 함께 갱신한다.

참고 인스타그램 영상은 로그인 제한으로 세부 동작을 직접 확인하지 못했다. 요구사항은 대화에서 확인한 기능을 기준으로 한다.
